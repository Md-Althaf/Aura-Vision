## Aura-Vision 
Ever wanted to control ur laptop like ironman using ur fingertip . 
now u can using Aura Vision It uses open-Cv and python . 

## Features 
*media control : play/pause, next/previous track via hand gestures
*volume control : raise/lower volume, mute
*mouse control : move the cursor and click using your index finger and pinch gesture
*config driven : camera, sensitivity, and cooldown settings live in config.json -no code editing needed
*Auto camera detection : automatically finds the working webcam
*Easter egg : a hidden "rockstar mode" gesture that glitches the video feed plays the song

## How to use it 
You can use the application in either of the following ways:

### Option 1: Clone the Repository

1. Clone the repository:
   
   git clone <repository-url>
cd <repository-folder>

2. Make sure you have Python 3.12 installed. Python 3.12 is the recommended version.

3. Install the required dependencies:
   
   pip install -r requirements.txt

4. Run the application:
   
   python main.py

### Option 2: Use the Executable Release

If you don't want to install Python or the dependencies, you can use the pre-built executable release.

1. Download the ".zip" file from the latest release.
2. Extract the ZIP file.
3. Keep the ".exe" file and "config" file in the same folder.
4. Place your song file in the same folder and name it:
   party.mp3
5. Run the ".exe" file.

Note: If your song has a different name or is located in another directory, update the song path in the "config" file accordinly.

Folder Structure

Your folder should look something like this:

Aura_Vision/
├─ AuraVision.exe
├─ config
|--party.mp3

Once everything is in place, simply run the executable.

Recommended Python Version: Python 3.12
